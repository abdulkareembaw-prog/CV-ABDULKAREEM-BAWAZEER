# موقع السيرة الذاتية

نسخة مطابقة للملف HTML المرفق، دون تعديل المحتوى أو التصميم.

## الاستخدام
افتح `index.html` في المتصفح، أو ارفع الملف إلى مستودع GitHub للنشر عبر GitHub Pages أو Cloudflare Pages.

## ملاحظات
- تنسيقات CSS مضمّنة داخل HTML الأصلي.
- خط Cairo يتم تحميله من Google Fonts ويتطلب اتصالاً بالإنترنت.
- لم تُجرَ أي تغييرات على بيانات السيرة الذاتية أو شكل الموقع.
